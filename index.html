FREQUENTLY ASKED QUESTIONS

KNOW YOUR GUARD.

What is CyberGuard?+

CyberGuard is a desktop security application that brings protection status, scanning, password tools, and local AI into one interface.

Is CyberGuard an antivirus engine?+

No. CyberGuard acts as a security dashboard and controller around supported security tools such as Microsoft Defender.

Does the Password Checker upload my password?+

No. Password strength is evaluated locally in the application.

Does CyberGuard AI need internet?+

The current AI feature uses Ollama locally. Once the required model is installed, its conversations can run without internet access.

When can I download CyberGuard?+

The Windows installer will be released after the final build has been tested.
